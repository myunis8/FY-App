Pesos por hora = (cobrado − gastos) ÷ horas-hombre. Sólo las obras pagadas cuentan para el promedio; las demás se muestran atenuadas con el valor provisorio (lo cobrado hasta ahora). No se usa ningún costo por hora cargado a mano.
