# Estándares de desarrollo

Siempre:

✔ mantener el estilo existente

✔ reutilizar componentes

✔ mantener nombres descriptivos

✔ evitar funciones enormes

✔ comentar únicamente código complejo

✔ eliminar código muerto

✔ evitar duplicación

✔ mantener compatibilidad

---

Nunca:

✘ reescribir módulos completos

✘ cambiar APIs públicas

✘ modificar nombres de archivos sin motivo

✘ agregar librerías innecesarias

✘ cambiar formato del proyecto

---

Cuando una modificación afecte varios módulos explicar primero el impacto.
